# Icon attribution

The SVGs in `app/assets/icons` are extracted from the following icon sets.
They are used as CSS masks. The EOS rotating gear's embedded animation was
removed and replaced with a CSS animation.

- `circle-minus.svg`, `circle-plus.svg`: [Akar Icons](https://github.com/artcoholic/akar-icons) by Arturo Wibawa, [MIT](akar-icons.txt).
- `ghost.svg`: [IconPark](https://github.com/bytedance/IconPark) by ByteDance, [Apache-2.0](iconpark.txt).
- `tiger.svg`, `mountain.svg`: [Emoji One (Monotone)](https://github.com/EmojiTwo/emojitwo) by Emoji One, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- `phoenix.svg`, `water.svg`, `gear.svg`: [Font Awesome](https://github.com/FortAwesome/Font-Awesome) by Dave Gandy, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- `dragon.svg`: [Simple Icons](https://github.com/simple-icons/simple-icons) by Simple Icons Collaborators, [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).
- `rotating-gear.svg`: [EOS Icons](https://gitlab.com/SUSE-UIUX/eos-icons) by the SUSE UX/UI team, [MIT](eos-icons.txt).
- `star.svg`: [Bootstrap Icons](https://github.com/twbs/icons) by the Bootstrap Authors, [MIT](bootstrap-icons.txt).
